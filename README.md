Features advanced 3D animations, particle effects, mouse-tracking interactions, and immersive visual effects built with HTML5, CSS3, and JavaScript.

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Basic text editor (VS Code, Sublime Text, etc.)

### Installation

1. **Download the files**: Download all files to your local machine
2. **File Structure**: Ensure you have these files:
   ```
   portfolio/
   ├── index.html
   ├── styles.css
   ├── script.js
   └── README.md
   ```

3. **Open in Browser**: Simply open `index.html` in your web browser

### Local Development

For local development with live reload, you can use:

1. **Live Server Extension** (VS Code):
   - Install the Live Server extension
   - Right-click on `index.html` and select "Open with Live Server"

2. **Python Simple Server**:
   ```bash
   python -m http.server 8000
   # Then open http://localhost:8000
   ```

3. **Node.js Live Server**:
   ```bash
   npx live-server
   ```

## 🌐 Deployment

1. Upload files to a GitHub repository
